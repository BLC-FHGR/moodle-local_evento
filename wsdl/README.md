# WSDL Files

Place your Evento WSDL files in this directory.

## Required Files:
- `evento_webservice_v1_1.wsdl` (default, configure in settings)

## Setup:
1. Copy the WSDL file from your Evento installation
2. Verify the filename matches the setting in Local Evento configuration
3. Test the connection using the Development Console

## Notes:
- WSDL files are not version controlled for security reasons
- Make sure the WSDL file is readable by the web server
